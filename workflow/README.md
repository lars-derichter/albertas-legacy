# Workflow: het logboek van dit project

Deze map bevat een verhalend logboek van hoe deze repository gebouwd werd:
door Lars samen met Claude. Concreet werkt één Claude-sessie als manager, die
per grote stap een aparte worker-agent aanstuurt, het resultaat controleert
en pas daarna vastlegt. Dit logboek volgt dat proces stap voor stap.

Het dient meteen als showcase van productief werken met genAI in het
onderwijs: niet alleen het eindresultaat telt, maar ook de weg ernaartoe —
de opdrachten, de keuzes en de kwaliteitscontrole.

## Wat hier staat

Eén bestand per werkpakket, oplopend genummerd (`01-…md`, `02-…md`, …). De
bestanden zijn chronologisch: lees ze op volgorde om het verhaal te volgen.

## Format van een entry

Elk bestand legt vier zaken vast:

- **Opdracht:** wat de manager aan de worker vroeg, en waar dat vandaan kwam
  (de prompt van Lars, een beslissing uit het plan).
- **Aanpak:** hoe de worker het aanpakte — de stappen, de gebruikte
  referenties, de manier van werken.
- **Beslissingen:** de keuzes die onderweg gemaakt zijn, met de reden erbij.
  Zo zie je waar de vorm van het resultaat vandaan komt.
- **QC-resultaat:** wat de manager controleerde en of het slaagde. Geen
  commit zonder geslaagde controle.

## Conventies

- Geschreven in het Nederlands (Vlaams), regels afgebroken op 80 tekens.
- Echte prompts, vragen en antwoorden worden geciteerd in hun oorspronkelijke
  taal (vaak Engels), zodat het logboek eerlijk weergeeft wat er gezegd is.
